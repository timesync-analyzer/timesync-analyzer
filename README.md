Для установки ПО необходимо поставить Docker. Для этого копируем пакеты с Докером (`/home/zloyaloha/docker_offline`) на флешку.

Далее нужно сдампить необходимые Docker образы и аналогичным образом перенести их на носитель.

Перед тем, как ставить ПО где-то, нужно предварительно сдампить необходимые образы на диск.

```bash
docker save timescale/timescaledb:latest-pg16 -o timescaledb-image.tar
```
